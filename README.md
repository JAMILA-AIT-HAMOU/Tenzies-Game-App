# 🎲 Tenzies Game

My first React project — a fun and interactive dice game built with **React**, **JavaScript**, and **CSS**.

I started this project while following the **Scrimba React course**, then completed and customized it on my own by adding new features such as a timer, sounds, and a start screen.

## 🕹️ How to Play
- Roll the dice until all of them show the same number.  
- Click each die to **hold** its value between rolls.  
- You have **35 seconds** to win the game — if the timer runs out, you lose! ⏰  
- Celebrate your win with confetti and sound effects 🎉  

## 🛠️ Built With
- React (Create React App)
- CSS3 (custom dice styling and animations)
- JavaScript (game logic & timer)

## 🔊 Features
- Dynamic timer and win/lose sound effects  
- Start and restart screens  
- Confetti animation when you win  
- Fully responsive design
